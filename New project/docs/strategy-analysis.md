# 策略分析与课程报告提纲

## 基础人工策略

人工账户通过界面选择股票、方向、订单类型、价格和数量。限价单适合观察价格发现：买价达到卖价时才成交，未成交部分留在订单簿中。

## 自动策略

`Simulation` 使用定时线程触发 AI Trader。没有启用 LLM 时，示例策略围绕最新价上下 1% 随机挂出小额限价单，便于课堂演示。启用 LLM 后，`LlmStrategy` 发送最新价、五档深度和账户状态，并只接受受限 JSON：BUY、SELL 或 HOLD。没有 API Key、请求过快、HTTP 失败、JSON 无效或价格超出边界时统一 HOLD。

## 人工与自动策略比较

模拟结束后按总权益、收益率、最大回撤和成交量排序。应保持相同初始资金、股票和模拟时长，再比较人工与自动账户。收益率反映收益，最大回撤反映稳定性，成交量反映活跃程度；不能只用成交量判断策略优劣。

## 答辩重点

1. 订单簿为什么买单按价格降序、卖单按价格升序。
2. 为什么成交价采用先挂出的订单价格。
3. 为什么 `submitOrder` 必须同步，以及冻结现金如何避免同一账户重复下单。
4. 为什么 API 失败时采用 HOLD，而不是提交未经验证的订单。
